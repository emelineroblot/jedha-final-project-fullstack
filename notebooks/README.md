# 📓 Notebooks

Notebooks Jupyter pour l'exploration et l'analyse des données.

## Ordre d'exécution

1. **`01_exploration_naive.ipynb`**
   - Chargement et inspection initiale des données
   - Qualité des données (nulls, duplicatas, outliers)
   - Définition de l'architecture et variable cible

2. **`02_etl_pipeline.ipynb`**
   - Prototype du pipeline ETL
   - Transformation et nettoyage
   - Création du Data Warehouse

3. **`03_eda_avancee.ipynb`**
   - Analyse statistique approfondie
   - Visualisations (uni-variée, bi-variée, multi-variée)
   - Tests d'hypothèses

4. **`04_machine_learning.ipynb`**
   - Preprocessing des données
   - Entraînement modèles (régression, clustering)
   - Évaluation et fine-tuning
   - Sauvegarde modèles

## Convention

- Documenter chaque cellule avec des commentaires clairs
- Ajouter des titres markdown pour structurer
- Sauvegarder les résultats intermédiaires
- Exporter les scripts finaux dans `scripts/`
